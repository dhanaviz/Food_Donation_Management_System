
# Food Donation Management System

## Description
A Python-based backend prototype for managing food donations and volunteers.

## Features
- Create Food Donation
- View Available Donations
- Claim Donation
- Update Donation Status
- Track Donation Records
- Maintain User Records
- JSON File Storage
- Input Validation
- Exception Handling

## Technologies Used
- Python
- OOP
- JSON
- File Handling

## Donation Status
Available → Claimed → Picked Up → Delivered

## How to Run
Run the following command:

py food_donation_system.py

## Project Type
Backend Prototype
